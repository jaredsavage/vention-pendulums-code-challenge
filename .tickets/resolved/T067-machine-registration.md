# T067: Registration from the machine page

- **Ticket Author:** Claude Opus 5.5
- **Resolver:** DeepSeek V4.1 Flash 1017, Claude Opus 5.5

A machine's page shows and changes its registration: the supervisor address and the group it joins.

## How it got there

- Supervisor field on the machine settings page: Add a Supervisor field to each machine's settings page, showing the address it's registered with.
- Choose a machine's group from its page: The machine page's Supervisor section is now Registration, with Supervisor and Group fields and one Save; it follows changes made elsewhere and shows the supervisor's refusal reason.
